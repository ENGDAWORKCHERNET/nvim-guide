Neovim Basics


What is Neovim?

Neovim is a modern, fast, keyboard-driven text editor built on top of Vim. It runs in your terminal (or its own window), starts in milliseconds, and lets you edit text without ever touching your mouse. It has a steep learning curve, but once it clicks, you'll never want to go back to a traditional editor. LazyVim is a pre-built configuration for Neovim that bundles the most useful plugins, sensible defaults, and keyboard shortcuts — so you get a professional-grade setup without having to build it yourself.



The Four Modes

Neovim is modal — meaning the same keys do different things depending on which mode you're in. This is the single most important concept to understand. Normal mode — The default. Used for navigating, deleting, copying, and running commands. Press Esc from any other mode to return here. Insert mode — For typing text. Press i to enter, Esc to leave. Visual mode — For selecting text. Press v for character selection, V for line selection. Command mode — For running commands. Press : to enter, Esc to cancel. Rule of thumb: if you're not typing text, you should be in Normal mode.
